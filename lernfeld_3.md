# Lernfeld 3: Clients in Rechnernetzwerke einbinden

## Themen
- Netzwerkgrundlagen, Netzwerkarten (LAN, WLAN, VLAN, VPN, SAN, PAN, WAN, MAN, GAN)
- Client-Server-Prinzip
- Internet, ISP, Intranet und VPN
- IP-Adressierung (IPv4/IPv6), Subnetting, MAC-Adresse
- Ethernet-Frame, Datenübertragungsrate
- OSI-Modell (7 Schichten), TCP/IP-Modell (4 Schichten)
- Protokolle und Dienste (DHCP, ARP, DNS), Ports
- VLAN und Sicherheit
- Strukturierte Netzwerkverkabelung, Kupferkategorien, Netzwerkdokumentation

## Merksätze
- Ein Netzwerk dient dazu, Ressourcen gemeinsam zu nutzen: Dateien, Drucker, Internetzugang.
- Beim Client-Server-Prinzip stellt der Client eine Anfrage, der Server verarbeitet sie und schickt die Antwort.
- IPv4 hat 32 Bit (4 Oktette), IPv6 hat 128 Bit. Eine IP-Adresse besteht aus Netzanteil und Hostanteil.
- Private IPv4-Bereiche: 10.0.0.0/8, 172.16.0.0 bis 172.31.255.255, 192.168.0.0/16.
- Ein /26-Netz hat 64 Adressen und 62 nutzbare Hosts, weil Netz- und Broadcast-Adresse nicht vergeben werden.
- Die MAC-Adresse ist die physische Adresse einer Netzwerkkarte (6 Byte). Die IP-Adresse ist die logische, netzwerkübergreifende Adresse.
- DHCP vergibt Adressen automatisch (Discover, Offer, Request, Acknowledge). ARP löst IP in MAC auf, DNS löst Namen in IP auf.
- Wichtige Ports: FTP 21, SSH 22, SMTP 25, DNS 53, HTTP 80, HTTPS 443.
- Übertragungszeit: t = D / C (Datenmenge durch Datenrate). 1 Byte = 8 Bit.
- Ein VPN ist eine verschlüsselte Verbindung über ein öffentliches Netz, zum Beispiel für sicheren Fernzugang.
- Ein VLAN trennt logische Netze auf einem physischen Switch (VLAN-ID 1 bis 4094).
- Kabellängen: Permanent Link max. 90 m, Channel Link max. 100 m.
